# RayRender3D

Render 3D models in Java using ray tracing with the Phong illumination model.  
Originally developed for the ISE course at JCT (2024), with additional features added afterward.

## Features
- Phong Illumination Model
- Supports planes, spheres, triangles, polygons, tubes, and cylinders
- Multiple Light Sources
- Transparencies and Reflections
- Glossy and Diffuse Surfaces
- Soft Shadows
- Render scenes from XML configuration files
- BVH and Threads-pool
